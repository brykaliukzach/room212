Getting Started

Your job is to turn your spreadsheet into one that looks like mine:

What To Create

First you need to add 5 more columns of data - Revenue Per Item, Total Possible Revenue, Week 1 Revenue, Remaining Quantity and Order More?. Use formulas to calculate the values for these columns, and use an If Statement for the Order More column. We are checking IF the quantity is 30 or less, and if it is, "YES" we need to order more.

You'll need to use multiplcation for some of these formula calculations. Use the asterisk * to perform multiplication. (SHIFT 8)

For example, 
=A1 * AB

Formatting

Once you have your values calculated, SORT your table based on the highest revenue making items in week 1. Also use Conditional Formatting to highlight the items that are the most Revenue per Item

You need to calculate the average of each three test scores across the whole class. You'll need to use =COUNTIF to determine the total number of students who have passed and failed.

Lastly, create a pie chart based on the number of students passing and failing.
