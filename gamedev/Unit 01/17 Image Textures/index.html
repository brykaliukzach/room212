Image Textures

Materials don't just have to be one colour. They can instead have image textures applied to them.

AmbientCG.com

AmbientCG.com is a website you can use to find high quality textures of various surfaces. From brick, to stone, to grass, this website will allow you to apply a photorealistic texture to your materials. These textures have some many cool files attached to them, more than we need at the moment. For now, we're just intested in the _Color file that comes with the package.

Shading Window

Blender as mentioned is an extremely intense software. At the top, we can view the SHADING tab which has so many crazy and complicated tools to make your materials look beautiful. We are going to keep this simple for now.

Nodes

In the Shading workspace, we can add an Image Texture node to our material. This node allows us to choose an image file and use it as a texture. We then connect the Image Texture node to the Base Color to apply the image to our object.

Key Takeaways

  • Use AmbientCG.com to download high quality textures
  • Just use the _Color file of the texture pack
  • Create an image texture node and load the _Color file
  • Hook up the color from the node to the Base color of the main principle texture
