Edit Mode

Let's explore some cool stuff you can do in Edit Mode while creating a little camping tent.

Extrude Tool

In edit mode, you can click on a face once you're in Face Select mode, by pressing 3 on your keyboard. Once you have a face selected, press E to extrude the face. This allows you to "extend" the face along its normal direction.

Merge

In Edit Mode, you can join two separate vertices to meet in the middle. To do so, make sure you're in vertice select mode by pressing 1, then hold SHIFT to select the vertices you want to join together. Once you've done that, press M to bring up the Merge menu, and simply press ENTER.

Fill Tool

If you a bunch of edges with no face joining them, you can hold SHIFT to select the edges, and then press F to FILL the gap with a face.

Knife tool

The knife tool can be used to cut out a face where there otherwise is no vertices to work with. In edit mode, press K to use the knife tool. Now you just click to add vertices, and once you're done, press ENTER to cut a face into the mesh you're working with.

Modifiers

Modifiers are handy little tools that allow you to make changes to your mesh without changing the acutal structure of it. In this video, you will learn about the Solidify modifier, which allows you to give thickness to your mesh

Solidify

Modifiers must be used in Object Mode, so make sure you're not still in edit mode. Select your mesh, click the blue wrench icon, and add a Solidify modifier. Play around with the properties, and once your mesh looks solid or thick enough, make sure you APPLY THE MODIFIER before moving on.

Key Takeaways

  • Learn how to Merge, Extrude, and Fill in edit mode
  • Use Modifiers for more advanced mesh changing tools.
  • Modifiers must be used in Object Mode
  • Apply the modifier once you're happy with the look
