Array & Curve Modifiers

Let's create a wishing well, but use some new modifiers to make this a quick task

Apply the Scale

When you're originally modifier yur starting mesh, once you get it scaled to your liking, please always remember to APPLY THE SCALE. This will save you from so many headaches moving forward

Array Modifier

The Array Modifier lets you create multiple copies of an object automatically.For example, if you have one brick, an Array Modifier can re create that brick as many times as you need to. And it can separate them uniformally in a straight direction

Curve Modifier

Allows you to bend an object, around the curve of another object. For example, if I put an empty circle on the ground, I can use the Curve modifier to bend my bricks around this perfect circle.

Apply The Modifiers

Once again, when you are happy with how your modifiers have modifier your mesh, make sure you APPLY them before moving forward

Key Takeaways

  • Don't forget to APPLY THE SCALE
  • Array Modifier creates duplicates of a mesh
  • Curve Modifier let's you curve an object around a path
  • Apply your modifiers
