Getting Started

Blackjack is a card game where the objective is to get as close to 21 as possible. You flip cards one-by-one, your score adding up with each flip. But be careful, as if you go over 21, you lose. Face cards (jacks, queens, kings) are worth 10, the rest of the cards are worth their respective values.

The DrawCard function is adding up the player's score. So when the dealer uses this function, the cards are getting added to the player's score, not the dealer's score.

To fix this, let's make a boolean variable called playerTurn 

bool playerTurn = true;

It starts as true because when the game starts, it's the player who first plays. However, we know it's the dealer's turn when the user has pressed the btnHold button. So let's turn this boolean variable to false in the ClickEvent for the hold button 

bool playerTurn = false;

Now we can correctly modify or DrawCard function. IF it is the player's turn, we're increase the player's score variable. ELSE we'll update the dealer's score variable.
