Switch Statements

We've used if statements to make decisions in our programs. But there's a second common method of decision making in programming - called switch statements

Switch Statements

Imagine checking which menu option a user selected, or which card was randomly generated in a game. Writing a large chain of else if statements can get messy pretty quickly. That’s where switch statements help. A switch statement lets us compare one variable against many possible values in a cleaner and more organized way.

Switches make decisions on one specific variable. We are checking for possible values. Each of these checks is called a case.

switch (month)
{
    case "january":
        lblOutput.Text = "Happy New Year!";
        break;
}

Above, we are checking if the month is equal to january
If that's the case, our program outputs "Happy New Year!"
The break command is used to exit out of the switch statement.
Because once we find the correct case we don't need to check the following cases

It works just like an if statement, except keeps things nice and tidy when you have multiple possible values to check for

switch (month)
{
    case "january":
        lblOutput.Text = "Happy New Year!";
        break;

    case "february":
        lblOutput.Text = "Happy Valentines!";
        break;

    case "march":
        lblOutput.Text = "Happy St. Patty's!";
        break;
}

And just like how if statements can have a fallback else condition, switches can to. Except for switches, it's called the default case

switch (month)
{
    case "january":
        lblOutput.Text = "Happy New Year!";
        break;

    case "february":
        lblOutput.Text = "Happy Valentines!";
        break;

    case "march":
        lblOutput.Text = "Happy St. Patty's!";
        break;

    default:
        lblOutput.Text = "I don't know what month you're talking about";
        break;
}

Nice clean code is not emphasized too much in this starter course, but the principal of clean code is super important moving forward with your programming career. Switches allow us to make cleaner code sometimes, instead of if statements

Important

if statements can do anything a switch statement can.

Each case ends with a colon : not a semi-colon ;

Key Takeaways

  • switches work like ifs
  • cases work like else ifs
  • default cases works like theelse statement
