Multiple Conditions

We’re going to expand on our decision making in by checking multiple conditions at the same time. Up until now, we’ve mostly checked one thing in an if statement, like whether a number is greater than 10. But real programs often need to check more than one condition before deciding what to do.

Multiple Conditions

It can be incredibly useful to check for multiple conditions - often times we have too to make our program behave the way we want. For Example:

Is a student’s mark above 50 AND attendance above 75%?
Is the username correct AND password correct
Did the player press a key OR click the mouse?

Important

&& means "and" in programming - (hold shift and press 7 on your keyboard)

|| means "or" in programming - (hold shift and press the key above your enter key)

AND

Often we need to check if not just one condition is met, but two conditions - or three, four, five. For example, maybe we need to check a student's grade and a student's attendence. There's two ways to do this. 

if (grade >= 50)
{
      if(attendance >= 75)
      {
          // the student passes
      }
}

Above is called a nested if statement. If the first condition is met, we go inside and try to meet the second condition. But we could also just use the && operator. 

if(grade >= 50 && attendance >= 75)
{
      // the student passes
}

Using the && operator makes our code a little easier to read in this situation.

OR

If you have multiple conditions, you may only need ONE of the conditions to be true. For example, maybe we want to give customers a discount if they are a child OR they are a senior. For this, we can use the || operator. 

if(age <= 13 || age >= 65)
{
      // apply discount
}

So as long as the person is under the age of 13, OR over the age of 65 - they get a discount

Key Takeaways

  • && means "and"
  • || means "or"
  • A single if statement can have as many conditions as we want
