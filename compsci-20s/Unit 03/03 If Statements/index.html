If Statements

If Statements are incredibly useful in programming. It's hard to program useful programs without them! These statements allow our programs to make decisions. Up until now, our code has mostly run from top to bottom in order. But real programs need to react to different situations.

If Statements

are used to check if a defined condition is met. If the condition is met, any code inside the If's block will execute. 

if (a condition)
{
      // all the code inside this block executes
      // .. if the condition was met
}

To keep things simple, we will start with the equals == condition. This very common condition can check if something is equal to something else. 

int age = 18;

if (age == 18)
{
      Messagebox.Show("You are 18 years old");
}

As you can see, the definied condition of age being equal to 18 is met. Therefore, the code within the block of this if statement will execute.

If Statements with Random Numbers

Combining this with the previous page on random numbers, we can create randomness, and react to that randomness very easily. 

int randomNumber = rand.Next(3);

if (randomNumber == 0)
{
      // it will become sunny in our game
}
else if (randomNumber == 1)
{
      // it will become cloudy in our game
}
else if (randomNumber == 2)
{
      // it will become rainy in our game
}

So now I can use randomness to determine the weather in my game.

Important

When checking for different possible scenarios, you should use the else if statement after the first initial if. This connects the entire If branch, and makes sure at most only one of these conditions ever executes.

Key Takeaways

  • Using if statements to execute code if conditions are met
  • Using else if for checking different related conditions
  • All the code within the statement's block will execute
