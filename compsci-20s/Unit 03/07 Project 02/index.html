Coin Flip

Flip a coin, and land on heads or tails

Project Walkthrough

Project Overview

Getting Started

In this project you will write code to flip a coin. Obviously computers can't flip coins, but they can generte random numbers. If I want to flip a coin, I should generate a random number from two numbers.

What to build

I'm not just flipping a coin - I'm also guessing which side of the coin will show. So I can guess heads with the btnHeads button, or I can guess tails with the btnTails button. I'll need to keep track of my wins and losses as well. 

//Random tool
Random rand = new Random();

int wins = 0;
int losses = 0;
double winPercentage; // for later

If I click the Heads button, I'm guessing the coin will land on heads. So what do we have to do? Well first we have to flip the coin, and as stated earlier, this will be done by generating a random number. 

int randomNum = rand.Next(?) // you fill in the blanks

Then you use an if statement to check if the user guessed correctly. REMEMBER, you're generating a random number, either 0 or 1. if the random number is 0, it's like saying the coin landed on heads. If the random number is 1, it's like saying the coin landed on tails

Hints

To calculate the win percentage you can do this: 

winPercentage = (double) wins / (wins + losses);

Then use the correct .ToString(?) method to display it as a nice readable percentage.
