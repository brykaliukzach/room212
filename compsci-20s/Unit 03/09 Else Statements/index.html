Else Statements

We first looked at if statements, then we attached else if statements to them. The last thing we can do, is end with an else statement.

Else Statements

Else statements execute if no other condition is met. So if you're checking for some condition, and it is not met - the else statement code will execute. 

int temperature = 20;

if (temperature > 30)
{
      Messagebox.Show("It is hot outside");
}

Above, nothing will happen. We will not see a Messagebox because the temperature is not greater than 30. However, let's add an else to it. 

if (temperature > 30)
{
      Messagebox.Show("It is hot outside");
}
else
{ 
      Messagebox.Show("It is cold outside");
}

Now we've created a situation where a Messagebox will always appear. If the temperature is greater than 30, we will be told it's hot outside. Else we are told it's cold outside. If the initial condition is not met, the else is there to execute instead.

Key Takeaways

  • else is like the back up condition.
  • else is executed when no other previous conditions are met
  • else's allow you to ALWAYS have something execute
