Generating Random Numbers

Random numbers are extremely useful in programming. They’re used in games, dice rolling, card systems, guessing games, simulations, and even things like enemy AI or loot drops.

The "Random" Tool

In C#, we need the Random class to generate random numbers. It's far to early to explain what a class is, so for this course we will call it a tool. So in other words, we need to use the Random tool to generate random numbers 

Random rand = new Random();

The above line of code goes where our variables normally go, and this will allow us to use this tool in our program. To use this tool, we must use the name of the tool. We can name it whatever we want, but conventionally when it comes to the Random Tool, we call this tool rand

Using the "Random" Tool

Now that we included the Random tool in our program, we can use it to start generating random numbers. Let's make a variable named randomNumber 

int randomNumber;

This variable is null (it doesn't have a value right now). But there are a few ways we can store a random number in here 

randomNumber = rand.Next(3);

What do you think the above line of code does? Try to make sense of it before I explain it.

The above line of code will give you a random number from 3 possible numbers. Those numbers being: 0, 1 or 2. In programming, we like to start counting at number 0, so better get used to that. 

//This line of code stores a 0, 1, 2, 3, 4 or 5.
randomNumber = rand.Next(6);

A Second Way To Use the Random Tool

Instead of starting at 0, you can specify the range you want your random numbers to be from. 

randomNumber = rand.Next(1, 5);

What do you think the above line of code does?

You probably think it will give you a random number from 1, 2, 3, 4 or 5. You'd be right to think that. But in C#, that line of code only gives you a random number from 1, 2, 3 or 4, it doesn't include the top value of 5 - it's always one less of your top number! 

// Stores a random number, either 3, 4, 5, or 6.
randomNumber = rand.Next(3, 7);

You've know unlocked this super useful tool to add to your programming arsenal - perfect for spicing up your programs in the future!

Key Takeaways

  • Include the Random tool in your program when you need to use it
  • Know the two ways to use rand.Next()
  • Programming likes to start counting at 0
