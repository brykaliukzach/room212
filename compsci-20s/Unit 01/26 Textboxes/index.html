Textboxes

Another super useful control to add to our programs is the Textbox. This is perfect for receiving input from our users.

Textboxes

Allow users to type in input into them. We can then use this input they've given us in our programs. Could be something simple lik their name, or some numbers we can do some math with.

Naming Textboxes

Textboxes use the txb prefix. So a proper example of a name for a textbox could be txbName, if we were expecting the user to input their name for us

Textbox's .Text

So once the user has typed inside the textbox, we need to be able to retrieve that text. To do this, we can use the .Text property of the textbox

txbName.Text   // This fetches the text that the user has entered

So for example, if I had a label where I wanted to display back to the user their name, I could do something like this

lblOutput.Text = "Hello " + txbName.Text + "! Nice to meet you.";

This looks a bit confusing, but what I'm doing is just typing in some text for this label and then I'm using the + symbol to ADD on the text from the textbox. This is called string concatenation.

txb.Text will be replaced with whatever text was put inside that textbox when the user sees this line of code execute.

Key Takeaways

  • Textboxes allow users to input text information inside them
  • Textboxes uses the txb prefix for naming
  • Use the textboxes .Text property to fetch that input they gave you
