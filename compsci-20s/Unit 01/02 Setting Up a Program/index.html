Setting Up a Program

Each time you create a new program, there are a few things you should do to setup up each of your projects correctly.

Form Rename

The FIRST thing you must do is change your Form1.cs name. You should rename it to what your program is about. You should also be re naming it in CamelCase form - which means no spaces, and capital letters separting each word. An example would be DiceGame.cs or TaxCalculator.cs

Form .Text Property

You should also click on your form and change the .Text property. This is the title of your form that you see when your program runs. You don't need to use CamelCase for this.

Icon

Your form's icon is the small image associated with the form window. This image must be an .ico file. JPEGs, PNGs will not work. You'll need to find an image to represent your program. There are two ways to do this:

Use a website like Icon-icons.com to find images already in .ico file formats.

OR find an image off google, and use a "PNG to ICO" converter website. A website like CloudCovert.com works well for me.

Change the form's Icon property to this image, THEN go into Project -> Properties and change the Icon there as well

Key Takeaways

  • You must do these three things everytime you create a program
  • Change the Form1.cs name
  • Change the form's .Text property
  • Find a .ico image to use as your form's icon
