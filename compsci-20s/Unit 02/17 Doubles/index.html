Doubles

We've worked primarily with two variables - strings to store words, and integers to store non-decimal numbers. We're going to look at a new variable type called doubles

Doubles

Just like integers, doubles store numbers. They can store positive or negative numbers, but they allow you to do one more thing - they can store decimal numbers as well. 

double cost = 89.99;

If you tried to use the above code with an integer, you would get an error - since there's a decimal attached to 89. But with doubles, you won't get an error.

REMEMBER

double is the variable type

cost is the variable name

89.99 is the variable value

When To Use Doubles

If there's ever a chance that some variable value, or some input from the user may contain a decimal, you must use a double. Even if there's no decimal in the moment - if at any point this variable value could have a decimal, use a double.

Common Uses

You will often use doubles when working with Money, Measurements, Percentages, Scientific Calculations, Average Scores

Parsing Text to Double

When taking a numeric value from the user, we can Parse to a double just like we did with integers.

cost = double.Parse(txbCost.Text);

When taking a numeric value from the user, we can Parse to a double just like we did with integers.

Key Takeaways

  • doubles are used to store numbers that DO or COULD have decimals
  • doubles are commonly used for money, percentages, averages
  • you can parse text to a double just like integers
