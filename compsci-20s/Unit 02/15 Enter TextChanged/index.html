Enter & TextChanged

We've really used one main event, and that is the click event - clicking on something. There are many other events. For example, the Enter and TextChanged events are specific to textboxes, and allow us to do some cool things.

Enter Event

The Enter event executes code when the textbox receives focus. That is, the user has clicked on it, or has tabbed to it. 

private void txbName_Enter(object sender, EventArgs e)
{
 
}

We can use this event primarily for one "Quality of Life" feature. That is, highlight all the text in the textbox when the user tabs to it. This is achieved with using the SelectAll() method

private void txbName_Enter(object sender, EventArgs e)
{
    txbName.SelectAll();
}

TextChanged Event

The TextChanged event executes code each time a character is typed or deleted into a textbox. 

private void txbName_TextChanged(object sender, EventArgs e)
{
    
}

This event is quite versatile - we can do a lot with it. But since we're just learning about it, we'll keep it simple.

For now, a nice "Quality of Life" feature is to hide previous outputs when the user types a new input. What I mean by that, is imagine the user has typed in a number in a textbox, you've done a calculation, and output some result to the user. If the user goes back to change the original number they typed, we should probably hide our previous output, because it doesn't match the new input.

private void txbName_Enter(object sender, EventArgs e)
{
    lblOutput.Text = "";
}

Key Takeaways

  • Enter & TextChanged events are for Textboxes
  • Enter executes code when the user tabs into a textbox
  • TextChanged executes code when the user types or deletes a character into the textbox
  • These two events should be included in all of your future projects that have textboxes
