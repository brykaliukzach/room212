Variables

You really can't make any cool programs without utilizing variables. In fact, you will never make another program in your coding career that doesn't use variables - mark my words.

What Are Variables?

When you think of variables, think of a real-life box. What do we use boxes for? We put things in them and store them until we need them later. Variables work the same way. A variable is a place where we can store information and use it again whenever we need it.

REFLECT

What's the last video game you played? What information about the player would need to be stored in that game?

Example

A super common example of storing information would be storing the name of the user's character. How do we do that? 

string playerName;

Above, I have declared a string variable called playerName. A string is a type of variable used to store text, such as words, letters, sentences, or other characters. Strings can also contain numbers, but when they do, the computer treats those numbers as text rather than numerical values that can be used for calculations.

Right now, I have created a box. It is empty and ready to store information. Let's store an actual name inside this variable.

string playerName = "Bob";

I have initialized this variable with the value of Bob. The Word "Bob" is being stored inside this variable. I can forget about "Bob", and reference the variable when I need to use this information.

NOTE

Just like controls, variable names' use camelCase naming

string player;
string playerName;
string playerAttackSpeed;

Using Variables

Creating a variable is only the first step. Once a variable has been created, we can use it throughout our program whenever we need the information stored inside it.

In the example below, the variable playerName contains the text "Bob". Instead of typing "Bob" every time we need the player's name, we can simply use the variable name playerName. 

lblOutput.Text = "It's nice to meet you " + playerName;

When this code runs, the label will display Bob. The computer looks inside the variable and uses the value stored there.

This is huge, because we didn't know our player was going to name their character "Bob", but we do know that whatever name they chose, will be stored inside the playerName variable. So we can always reference that variable, no matter what name they chose, or change it to!

Key Takeaways

  • Variables are like boxes
  • We use variables to store information inside them
  • String variables store letters, text, sentences, numbers if needed
