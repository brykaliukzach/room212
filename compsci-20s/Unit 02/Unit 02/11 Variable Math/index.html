Variable Math

One of the most useful things you can do with variables is perform mathematical calculations. Computers can add, subtract, multiply, and divide numbers stored inside variables.

Math Operations with Variables

Let's say I have a program, where I'm going to ask the age of two different people. First, I should create variables to store this information. 

int ageOfPerson1;
int ageOfPerson2;

I want to create a third variable named ageDifference, to determine what the difference in age of these two people are. 

int ageDifference;

I do not know what the ages of these two people will be, but I can use math to setup my program to easily calculate it. 

ageDifference = ageOfPerson1 - ageOfPerson2

Above, since all of these variables are integers, I can do math with them. I am taking the difference between ageOfPerson1 and ageOfPerson2 and storing the result in the third variable ageDifference

So for example, let's say someone is using my program, and enters 28 for the first age and 23 for the second age. Those numbers are being stored in the variables 

  ageDifference = ageOfPerson1 - ageOfPerson2
                =    (28)      -    (23)
                =              5

Therefore, ageDifference will have a value of 5, since 28 - 23 is equal to 5

This is super useful because you don't know what ages the user is going to enter. But you can setup your program with the proper code to handle any case. Doesn't matter what numbers the ages are, we know we have to subtract those two ages, and we will end up with the correct answer.

Key Takeaways

  • Use math operations to perform calculations on variable values
  • + performs addition
  • - performs subtraction
  • * performs multiplication (HOLD shift and press 8)
  • / performs division
  • / You CANNOT perform math on strings
