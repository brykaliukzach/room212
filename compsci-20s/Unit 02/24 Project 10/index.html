Project Walkthrough

Part 1 - Setup

To start, create a new program that looks like mine above. My form has a background image, a picturebox, 4 labels, 1 textbox and 1 button. I have some image resources you can download, where you can choose from some already created characters. My characters have three different poses each, one for idle, idle_attack, and attack. Whatever character you choose, choose the idle image to start.

ALSO CHANGE THE DoubleBuffered property of your form to be TRUE. This makes your form a lot less laggy!

Part 2 - Trackbars

As you can see, our character has three attributes - Strength, Agility, and Vitality. More on these attributes later, but first we need to give our user a way to set these attributes.

We're gonna use something new - Trackbars. Add three trackbar controls to your program. I have also added three more labels to show the values of each trackbar.

We can also change the following properties of these trackbars:

Maximum - set to 100

Minimum - set to 0

TickStyle - set to none

Name - use tb as the prefix

What these trackbars do is allow the user to slide to a value between our minimum and maximum. In this case, our min is 0 and our max is 100 - so they can choose any value between 0 and 100.

Part 5 - Constraints

Now what fun would this program be if the user was free to set the attributes as they pleased - they'd always set them to 100. Let's only give them 150 points to spend, so they have to be smart with their choices. Let's create an attributePointsLeft variable and set it equal to 150. You might not see it yet, but you will need this constant to help you with the next part's math.

const int INITIAL_ATTRIBUTE_POINTS = 150;

Now back in your trackbar scroll events, you have to come up with a way to accurately update this attributePointsLeft variable. You will need to perform some math, using almost all of the variables we have created so far. This is tricky, but a good problem for you to solve on your own. Good luck.

You can also create a new label to update and showcase this information to the user.

Part 7 - Attributes to Combat Stats

We've got these attributes, but they don't really mean to much to us. In a fighting game, stats like these mean more:

int playerDamage;
int playerAttackSpeed;
int playerHealth;

Add these variables at the top of your program. What we now need to do, is use our previous attributes to calculate values for these new variables. We will do this when the user clicks the FIGHT button.

Sometimes good code doesn't equate to good game logic. So I will show you my calculations for deriving game stats from these attributes

playerDamage = 10 + (int) ((strength * 0.7) + (agility * 0.3));
playerAttackSpeed = 1000 - (agility * 5) - (strength * 2);
playerHealth = 100 + (vitality * 8) + (strength * 2);

What I'm trying to do here, is end up with a health around 1000, an attack speed around 1000 (one second), and a maxHealth around 100. BUT how the user chooses their attributes will affect these numbers, giving some deviation between different builds.

This is a simple way MMORPG games can take attributes and calculate combat stats from them. Pretty cool!

Our enemy, we can just hard code its' combat stats, since they're not creating their own character.

enemyAttackSpeed = 1000;
enemyHealth = 800;
enemyDamage = 90;

Now that our calculations and character creation is complete, let's get the fight ready. First, we are going to need to make a bunch of controls invisible, while making some new controls visible.

A bit of a pain, but make all those controls on your screen invisible. You'll also need to create some new pictureboxes, one for the player's character_attack_idle pose and one for the enemy you have chosen. You'll also need to show the health of the player and enemy, showing the correct health from the previous variables.

Part 9 - The Fight

To simulate the fight, we will need two timers. a tmrPlayer and a tmrEnemy. Turn these timers on at the bottom of your FIGHT button event, and set their intervals to the player's attackSpeed, and the enemyAttackspeed. Also remember to enable the timers!

The timer tick events work very similar. For example, in tmrPlayer, each time it ticks you will need to decrease the enemy health by the damage of the player. Then update the label to show the new health of the enemy. Do the exact same, but opposite for the tmrEnemy

Your program should function like THIS when you are done.
