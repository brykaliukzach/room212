ToString

Sometimes in programming, you have a number stored in a variable, but you want to display that number as text.

String Concatenation

When displaying numeric values in your program (often as .Text of a label) we have used string concatenation. 

double money = 3.50;
lblOutput.Text = "You have " + money + " dollars";

Above, we have combined some words with a our money variable.

At this point, we know that .Text is expecting a string. When a string is combined with a number using the + operator, C# automatically converts the number into a string before joining them together. Therefore, no errors, no problem.

ToString Method

If you want to use a number variable in a label's .Text WITHOUT any other strings, you will get an error.

lblOutput.Text = money;  // ERROR

Because .Text needs a string and money is a double. This is where the .ToString method comes in.

lblOutput.Text = money.ToString();  // CORRECT

ToString as the name implies, converts to a string. Therefore, even though money is a double, we convert it to a string, and then the .Text can properly show this value, because it is now a string. And .Text needs a string.

ToString Formatting

We can also use the ToString method to format our text.

FORMATTING

ToString("C") makes the text look like money

ToString("P") converts a decimal to a readable perentage

Above are two common uses of ToString formatting. Here's how they work. 

double money = 3.5;
    
lblOutput.Text = money.ToString();       // Displays 3.5
lblOutput.Text = money.ToString("C");    // Displays $3.50
   
const double TAX_RATE = 0.12;
    
lblOutput.Text = TAX_RATE.ToString();       // Displays 0.12
lblOutput.Text = TAX_RATE.ToString("P");    // Displays 12.00%
lblOutput.Text = TAX_RATE.ToString("P0");    // Displays 12%

The above percentage format is cool, as you can also declare how many decimal places you want the percentage to show. Above, I put ("P0"), the 0 meaning zero decimal places.

Key Takeaways

  • const makes a variable a constant.
  • Constants cannot change value once they're set
  • Use constants if you have a variable that won't change value
  • Use constants to replace Magic Numbers in your code (Numbers without meaning)
  • Constants make your code easier to read and easier to change
