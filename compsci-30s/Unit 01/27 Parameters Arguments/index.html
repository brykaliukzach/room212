Parameters & Arguments

At a base level functions are pretty easy to use. But they lose their usefulness quick if you don't learn how to create interesting function definitions

Parameters

We can send information (variables) to functions. For example, let's say I wrote a Greeting() function. 

static void Greeting()
{
    Console.WriteLine("Hello!");         
}

The above function will just always say "Hello!. It doesn't say hello to anyone or anything specific, just "Hello". That's not that useful. I want this function to say "Hello" to a specific thing.

In the function parentheses (), I can create a function that expects more information - such as the name of the thing I want to greet. 

static void Greeting(string name)
{
    Console.WriteLine("Hello! " + name);          
}

Now my function is EXPECTING SOME INFORMATION before it executes. In this case, it's expecting the name of the thing it's supposed to greet. This is called a parameter. A parameter is something the function is expecting to receive. In this case, a string variable

Arguments

If your function has a parameter, if it is expecting information, when we call the function we have to send it the information that it wants. This is called an Argument

  Greeting();  // this won't work anymore

When you call the function, you put the information to send inside the empty parentheses. This is called an argument 

  string name = "Bob";

  Greeting(name);
  Greeting("John");

The above function calls work, because in each case I am sending the function information. I am sending the function a string, which is exactly what the function is expecting.

The string gets sent to the function, and the function uses that string in it's code.

  "Hello Bob!"
  "Hello John!""

This is great because I can now use the same function for all the greetings in game. I just have to send the write information for who I want greeted

Key Takeaways

  • Parameters are "information" a function requires
  • Arguments are the "information" you send to a function
  • This allows our functions to be re-used much easier
