Multiple Conditions

Sometimes a program needs to check more than one condition before making a decision. Is the user over 18 AND do they have a ticket for the show?

The && Operator (AND)

Here we have an if statement checking if one thing is true. 

if (age >= LEGAL_AGE)
{
    
}

But what if I want to check if they have a ticket? Well I can use a boolean variable, and include it in the same if statement. I don't need to make a separate if statement 

if (age >= LEGAL_AGE && hasTicket == true)
{
    
}

Now the if statement is both checking if they are above legal age, AND if they have a ticket to go see the show.

The || Operator (OR)

There's also an OR operator. This allows us to check for multiple conditions as well, but only ONE of them has to be true. One or the other. Not both. 

if (age >= LEGAL_AGE || hasTicket == true)
{
    
}

So this if statement fires off if one of those two conditions are met. Are you over 18, but don't have a ticket? Sure that's fine. Are you under 18, but you still have a ticket? Sure that's fine too. Just one condition has to be met.

Key Takeaways

  • If statements can check multiple conditions
  • && means AND
  • || means OR
