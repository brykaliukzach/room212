Constants

Writing code that anyone can understand is a benchmark of good programming. To make your code more readable, more understandable, we can use constants.

Magic Numbers

Magic numbers are numbers in your code without any surface level meaning. 

speed = seconds * 9.81;

Look at the above code. Do you know what 9.81 represents? If you do, do you think everyone else understands what it means? Chances are no.

Constants

Constants are used to prevent magic numbers from appearing in your code. Instead of having a random 9.81 sitting in your code, we can instead create a constant to give this number some meaning. 

const double GAME_GRAVITY = 9.81;

speed = seconds * GAME_GRAVITY;

I've given the 9.81 meaning. Now anyone that looks at my code understands that I'm calculating the speed of a falling object based on seconds and gravity.

Constants can never change when your program is running. So constants should be used to not only give clarity to your code, but to also "lock in" values that you don't want to accidentally change later on in your code.

Naming Constants

To create a constant, just put the word const, and then create a variable like you normally would

const double GRAVITY = 9.81;

Proper naming of constants requires the user of ALL_CAPITAL_LETTERS. Constants with longer names can use the underscore _ to join each word into one long name.

Key Takeaways

  • Magic Numbers are numbers in your code without meaning
  • Swap out magic numbers with constants that have meaning in their name
  • Constants can't change when your program is running, so it "locks in" the value
