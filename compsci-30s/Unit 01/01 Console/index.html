The Console

For this course, we are not always going to do what we did last course - create graphical user interfaces (forms) for our programs. We can use a different template to just worry about the code, and only the code.

The Console

The console is a text-based interface that allows a program to communicate with the user. In C#, we can use the console to display information, ask the user for input, and interact with the program through text. Console applications are useful for learning programming because they allow us to focus on the code and logic of a program without worrying about designing a graphical user interface.

WriteLine

A new method is the WriteLine() method. This method allows us to write a string to the console, displaying it for the user to see. 

Console.WriteLine("Hello World!");

What ever string you put inside this method will be displayed as it to the user when they run your application.

ReadLine

The second new method is the ReadLine() method. This method allows us to receive information back from the user. However for now, we are just going to use it to stop our program from exiting itself. 

Console.ReadLine();

In the next lesson, we'll see how we can use the ReadLine() method to retrieve and re use information the user has given us.

Key Takeaways

  • How to create a Console Application
  • Console Apps allow us to code without worrying about fancy graphics
  • For now our code goes in the Main method
  • How to use WriteLine() and ReadLine()
