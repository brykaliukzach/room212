Square

Perform calculations given a side length of a square

Project Walkthrough

Project Overview

This project allows the user to enter the side length of any square, and for you to calculate the correct area and volume calculations for the square and cube.

Getting Started

We need one piece of information from the user, the initial side length - so need a variable for that. We will perform two calculations, so variables for those both would be great.

What to Program

Take the input from the user and store it in a variable. Then use that variable to calculate values for the area and volume of a square and cube with that same side length.

Hints

Use .ToString formatting to ALWAYS show one and only one decimal place.
