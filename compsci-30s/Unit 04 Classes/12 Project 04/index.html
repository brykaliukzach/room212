Pokemon Trainer Project

Keep track of your pokemon objects. Train and feed your pokemon

Project Walkthrough

Project Overview

This project keeps track of the user's pokemon, allowing them to activate one pokemon or create new pokemon. Active pokemon can be trained and fed.

What to Program

Add the methods from the above picture to your main program. Create a Pokemon.cs class with the fields and methods from the above picture. ALL POKEMON START AT LEVEL 1. Don't worry about coding the methods yet, we'll walk through those together.

In your main create a list to hold your pokemon. Add 3 pokemon to your list. I used

Name Type Health
Charmander Fire 10
Bulbasaur Grass 12
Squirtle Water 8

Main Method

Use a loop to give the user options for input. Note - only when a pokemon has been activated do you see the train, feed and deactivate pokemon options.But maybe we'll worry about this later . . .

ViewPokedex Method

Use a for loop to cycle through each object in your list of pokemon. Simply call the DisplayStats() method from your pokemon's class. Use a guard clause check if the list is empty.

ActivatePokemon Method

A bit trickier. You have to use a loop to show each of the pokemon, and then fetch an input from the user. Use input validation to make sure the user enters a correct number. *NOTE* your pokedex can shrink and grow, so hard coding values won't work. Gonna need to utilize the .Count method for lists.

Once you have the input (or desired index from the user), you're going to need to hold on to that information back in the main. So think of a return type, and think of how you'll store this information back in the main . . .

Use a guard clause to check if there is any pokemon to activate to begin with

CreatePokemon Method

Ask the user to choose a name for their pokemon. Once they've chosen a name, use a loop to check that no pokemon already exist with that name in their pokedex.

Ask the user to enter the type of pokemon. Whatever, they can enter whatever they want.

Use input validation to get a number for the health.

Once you have all three required pieces of information, create a new pokemon object and add it to your pokedex list.

Pokemon class methods

Your pokemon class should have a Train method, an Eat method, and a Display stats method. I just had some fun with Random numbers and Thread.Sleep to simulate training and eating. Do whatever you want. HOWEVER the train method should increase your pokemon's level by 1, and the Eat method should increase your pokemon's health.

Because you're keeping track of the active pokemon's index, you can easily call these methods with one line of code back in your initial while loop. One line of code is all you need
