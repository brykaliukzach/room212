Character Database Project

Given a database of information, log in to an account and display information

Project Walkthrough

Project Overview

This project allows the user to try to login to an account we have stored in our database. If they can, we will display the stats of that account's character.

What to Program

First we need the Login Function. This function loops, continually asking the user to enter a username and a password. Once you have these inputs, loop through the appropriate array trying to find a match for the usernames. Then check if the password matches too. If both pass, return the index where this match occured.

Then call the DisplayStats() function. This function does need need to loop through any arrays, because you are sending it the correct index and the arrays with the information you need. Simply display the stats of the correct index, and you're good to go!
